# Лабораторна робота №16. Пошук маршруту

- **Дисципліна:** Алгоритми та структури даних
- **Група:** ІПЗ-3/1
- **Мова програмування:** C#

## Що реалізовано
- **`Dijkstra(graph, start)`:** пошук найкоротших шляхів за часом у хвилинах з використанням `PriorityQueue`, множини остаточних вершин `done` для пропуску застарілих записів (`TODO 1`) та оновлення `dist` / `prev` при знаходженні меншого сумарного часу (`TODO 2`).
- **`BuildRoute(prev, start, target)`:** відновлення маршруту від кінцевого пункту до початкового за словником `prev` з розгортанням у прямий порядок або поверненням порожнього списку, якщо шляху немає (`TODO 3`).
